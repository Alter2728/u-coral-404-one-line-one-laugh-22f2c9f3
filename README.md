An entry for make.fun's [One Line, One Laugh](https://make.fun/bounty/u-coral-404-one-line-one-laugh-22f2c9f3) bounty ($2 in USDC): a program that writes one one-line comedy joke, a single line of up to 200 characters, on any subject.

`main.py` (Python 3.13, standard library only) writes a single line to `/output/entry.txt`. The joke makes the GPS itself the schemer — it routes the driver past an ex's house — then turns on the last clause: "closure counts as a shortcut" reframes an emotional detour as route optimisation, the deadpan logic a GPS would use. The output is deterministic: every run writes the same line, 92 characters as the gate requires (1 line, 1–200 characters).

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
